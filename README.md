## 📖 项目简介

TypeScript 是一门面向应用规模的 JavaScript 语言,由微软开发并持续维护。它在 JavaScript 的基础上加入了可选的静态类型系统,让大型前端与全栈项目的开发、重构和维护变得更加可控。TypeScript 最终会编译成干净、可读、符合标准的 JavaScript,可以运行在任何浏览器、任何宿主环境、任何操作系统之上。

本仓库是 [microsoft/TypeScript](https://github.com/microsoft/TypeScript) 官方 README 的中文翻译版本,方便中文开发者快速了解项目的定位、安装方式、贡献流程与官方文档入口。

## ✨ 主要特性

- **JavaScript 超集**:完全兼容 JavaScript 生态,现有 JS 代码即可逐步迁移。
- **可选静态类型**:类型系统按需启用,既能严格约束也能渐进 adoption。
- **编译产物干净**:输出可读、符合 ECMAScript 标准的 JavaScript 代码。
- **跨平台运行**:任何浏览器、任何宿主、任何操作系统都能承载编译结果。
- **工具链成熟**:配合编辑器获得强大的智能提示、重构与错误检查能力。
- **规模友好**:为大型应用而生,类型即文档,显著降低协作成本。
- **在线 Playground**:官方提供 [playground](https://www.typescriptlang.org/play/),浏览器里直接试语法。
- **持续演进**:通过官方 [博客](https://devblogs.microsoft.com/typescript/) 和 [Roadmap](https://github.com/microsoft/TypeScript/wiki/Roadmap) 公开未来方向。

## 🚀 快速开始

1. 安装最新稳定版(作为开发依赖):

```bash
npm install -D typescript
```

2. 安装每夜构建版(尝鲜最新特性):

```bash
npm install -D typescript@next
```

3. 在线体验:打开官方 [Playground](https://www.typescriptlang.org/play/),无需本地环境即可编写和编译 TS 代码。

4. 五分钟入门:阅读官方教程 [TypeScript in 5 minutes](https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html)。

5. 系统学习:查阅 [编程手册](https://www.typescriptlang.org/docs/handbook/intro.html) 与 [官网首页](https://www.typescriptlang.org/)。

6. 参与贡献:提交 [Issue](https://github.com/microsoft/TypeScript/issues)、审阅 [PR](https://github.com/microsoft/TypeScript/pulls),或在 [TypeScript Community Discord](https://discord.gg/typescript) 与其他开发者交流。
