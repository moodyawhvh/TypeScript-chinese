## 项目简介

[TypeScript](https://www.typescriptlang.org/) 是一门面向应用规模的 JavaScript 语言。TypeScript 为 JavaScript 加入了可选的类型系统,为任意浏览器、任意宿主环境、任意操作系统上的大规模 JavaScript 应用开发提供完善的工具支持。TypeScript 会编译成可读的、符合标准的 JavaScript 代码。

你可以前往官方 [Playground](https://www.typescriptlang.org/play/) 在线体验,并通过[官方博客](https://devblogs.microsoft.com/typescript/)和 [Twitter 账号](https://twitter.com/typescript)获取最新动态。

想了解还有哪些团队在使用 TypeScript,可以访问[社区页面](https://www.typescriptlang.org/community/)。

## 安装

安装最新稳定版本:

```bash
npm install -D typescript
```

安装每夜构建版本(nightly):

```bash
npm install -D typescript@next
```
